# Спортивная Варшава: MVP агрегатора событий

Next.js 14 (App Router) + Prisma + SQLite. Интерфейс на русском.

## Запуск

```bash
npm install
npm run setup     # создаёт базу prisma/dev.db и заливает демо-данные
npm run dev       # http://localhost:3000
```

## Что уже есть

- Главная: события по дням, фильтры по дате, типу, виду спорта, району и цене (фильтры живут в URL)
- Страница события: детали, цена, организатор, карта OpenStreetMap
- Страница площадок
- Форма «Добавить событие»: заявки сохраняются со статусом `pending` и не показываются на сайте

## Модерация заявок

Страница `/admin` (логин `admin`, пароль из переменной `ADMIN_PASSWORD` в `.env`): заявки из формы со статусом
`pending`, кнопки «Опубликовать» и «Отклонить». Без `ADMIN_PASSWORD` админка закрыта.

## Сбор реальных матчей (ingest/)

Источники (официальные страницы расписаний клубов) описаны в `ingest/sources.ts`, площадки в `ingest/venue-data.ts`.

```bash
npm run venues:sync     # добавить/обновить реальные площадки в таблице Venue
npm run ingest:fetch    # проверить robots.txt и скачать тексты страниц в ingest/out/pages/
# выписать матчи в ingest/out/extracted/<id>.json по правилам ingest/EXTRACTION.md (можно попросить Claude в чате)
npm run ingest:city     # городской каталог секций sport.um.warszawa.pl (≈40 минут в первый раз, дальше из кэша)
npm run ingest:dry      # проверить выписанное и показать, что будет записано
npm run ingest          # записать в базу (повторный запуск обновляет, а не дублирует)
npm run ingest:clear-demo            # показать демо-данные из seed.ts
npm run ingest:clear-demo -- --yes   # удалить их
```

Секции (регулярные занятия) хранятся в таблице Activity и показываются на странице «Секции» (/sections).
Городской каталог разбирается программой (`ingest/city-catalog.ts`): контакты не сохраняются, ссылка ведёт на страницу занятия.
Секции для пенсионеров на сайт не берутся (правило `isSeniorOnly` в `ingest/activities.ts`); ранее записанные скрыты статусом `hidden`.

Записываются только домашние матчи с объявленным временем. Каждый матч сверяется с текстом страницы по дословной цитате.
У события сохраняется ссылка на официальный источник (`sourceUrl`), она видна на странице события.

## Структура

- `prisma/schema.prisma`: модель данных (Sport, Venue, Organizer, Event)
- `prisma/seed.ts`: демо-данные (вымышленные, координаты приблизительные)
- `src/lib/dates.ts`: работа со временем Варшавы (Europe/Warsaw)
- `src/app`: страницы; `src/components`: фильтры и строка события
